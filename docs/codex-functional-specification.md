# Tetris Master 기능 명세

## 1. 제품 개요

Tetris Master는 테트리스 입문자가 조작키를 몸에 익히고, 이후 T-Spin 같은 중급 기술을 반복 훈련할 수 있는 웹 기반 연습 앱이다.

사용자는 초급 코스에서 기본 조작키와 그에 대응하는 블록 모션을 익히고, 중급 코스에서 실제 테트리스 상황에 가까운 기술 문항을 랜덤으로 풀며 숙련도를 높인다.

## 2. 목표

- 초급 사용자가 키 이름을 외우는 수준을 넘어, 화면의 블록 상황과 키 입력 결과를 연결해서 학습할 수 있어야 한다.
- 각 키 입력은 단순 정답/오답 표시가 아니라 해당 키에 맞는 블록 모션으로 피드백되어야 한다.
- 같은 키라도 여러 상황의 모션을 제공해 반복 학습이 지루하지 않게 한다.
- 중급 사용자는 T-Spin을 포함한 실전 기술을 상황별 모션과 함께 반복 연습할 수 있어야 한다.
- 초급과 중급 모두 랜덤 출제를 지원해 사용자가 특정 순서 암기가 아니라 실제 반응 능력을 기를 수 있어야 한다.

## 3. 사용자 수준

### 3.1 초급 코스

초급 코스는 기본 조작키 학습을 목적으로 한다.

대상 키는 다음과 같다.

| 동작 | 기본 키 | 설명 |
| --- | --- | --- |
| 왼쪽 이동 | `ArrowLeft` | 현재 블록을 왼쪽으로 1칸 이동 |
| 오른쪽 이동 | `ArrowRight` | 현재 블록을 오른쪽으로 1칸 이동 |
| 소프트 드랍 | `ArrowDown` | 현재 블록을 아래로 빠르게 내림 |
| 하드 드랍 | `Space` | 현재 블록을 즉시 착지 |
| 반시계 회전 | `Z` | 현재 블록을 반시계 방향으로 90도 회전 |
| 시계 회전 | `X` | 현재 블록을 시계 방향으로 90도 회전 |
| 180도 회전 | `A` | 현재 블록을 180도 회전 |
| 홀드 | `C` | 현재 블록을 보관하거나 보관 블록과 교체 |

### 3.2 중급 코스

중급 코스는 기본 조작을 이미 알고 있는 사용자가 기술 단위로 연습하는 것을 목적으로 한다.

초기 대상 기술은 다음과 같다.

| 기술 | 핵심 입력 | 설명 |
| --- | --- | --- |
| T-Spin Single | 이동 + 회전 + 드랍 | T 블록을 슬롯에 회전 삽입해 1줄 제거 |
| T-Spin Double | 이동 + 회전 + 드랍 | T 블록을 T 슬롯에 회전 삽입해 2줄 제거 |
| Mini T-Spin | 이동 + 회전 + 드랍 | 작은 슬롯에서 T 회전 판정을 익힘 |
| Tuck | 이동 + 회전/이동 | 블록을 이미 쌓인 구조 아래로 밀어 넣음 |
| 180도 회전 삽입 | `A` 중심 | 180도 회전을 활용해 반대 방향 구조에 삽입 |
| 홀드 활용 | `C` 포함 | 현재 블록과 홀드 블록을 교체해 더 좋은 배치 선택 |

## 4. 핵심 화면

### 4.1 코스 선택

- 사용자는 `초급`과 `중급` 코스를 전환할 수 있다.
- 현재 선택된 코스는 시각적으로 강조한다.
- 중급 코스가 아직 구현되지 않았더라도 버튼은 노출하고, 미구현 상태에서는 비활성 또는 준비 중 상태를 표시한다.

### 4.2 연습 화면 공통 구조

연습 화면은 다음 영역을 포함한다.

- 현재 문항 영역: 학습할 동작 또는 기술명, 설명, 목표 키 또는 키 시퀀스
- 모션 보드: 테트리스 보드, 현재 블록, 고스트 위치, 목표 위치, 애니메이션
- 입력 피드백: 사용자가 누른 키와 정답 여부
- 통계 영역: 연속 성공, 정확도, 시도 수, 성공 수
- 목록 영역: 현재 코스에서 연습 가능한 키 또는 기술 목록

## 5. 모션 요구사항

### 5.1 공통 모션 규칙

- 모든 문항은 정적인 텍스트만 보여주지 않고, 테트리스 보드 위의 모션으로 상황을 보여줘야 한다.
- 사용자가 키를 누르면 해당 키에 대응하는 블록 모션이 재생되어야 한다.
- 정답 키를 누른 경우 목표 모션과 결과 위치를 강조한다.
- 오답 키를 누른 경우 사용자가 누른 키의 실제 모션을 짧게 보여준 뒤, 정답 키와 정답 모션을 안내한다.
- 모션은 시작 상태, 입력 순간, 결과 상태가 구분되어야 한다.
- 같은 동작에는 최소 3개 이상의 모션 변형을 제공한다.
- 모션 변형은 해당 키의 의미와 잘 맞는 상황이어야 한다.

### 5.2 초급 모션 예시

| 키 | 권장 모션 변형 |
| --- | --- |
| `ArrowLeft` | 빈 칸에 맞추기 위해 왼쪽으로 1칸 이동, 벽 근처에서 왼쪽 정렬, 홈 위로 이동 |
| `ArrowRight` | 오른쪽 우물로 이동, 오른쪽 벽 근처 정렬, 다음 착지 위치로 이동 |
| `ArrowDown` | 착지 전 높이를 낮추기, 지형 위에서 천천히 내려가기, 회전 전 타이밍 조절 |
| `Space` | 고스트 위치로 즉시 착지, 긴 막대 블록으로 테트리스 우물에 하드 드랍, 빈 칸 위에 즉시 고정 |
| `Z` | L/J/T 블록을 반시계 방향으로 슬롯에 맞춤, 왼쪽 방향 홈에 회전 삽입, 벽 근처 반시계 회전 |
| `X` | T/S/Z 블록을 시계 방향으로 홈에 맞춤, 오른쪽 방향 홈에 회전 삽입, 평평한 지형 위에서 방향 전환 |
| `A` | 블록을 180도 돌려 반대 홈에 맞춤, S/Z 블록 방향 뒤집기, 막힌 구조에서 빠른 방향 전환 |
| `C` | 현재 블록을 홀드에 저장, 홀드 블록과 현재 블록 교체, I 블록을 나중에 쓰기 위해 보관 |

## 6. 랜덤 출제 요구사항

### 6.1 초급 랜덤 출제

- 초급 코스는 기본 키 8개 중 하나를 랜덤으로 출제한다.
- 같은 키가 3회 이상 연속으로 나오지 않아야 한다.
- 각 키는 일정 시간 동안 최소 1회 이상 출제되도록 균형을 맞춘다.
- 오답률이 높은 키는 이후 출제 확률을 조금 높일 수 있다.
- 사용자는 랜덤 모드와 순차 모드를 선택할 수 있다.

### 6.2 중급 랜덤 출제

- 중급 코스는 기술 단위로 랜덤 출제한다.
- 기술 문항은 난이도, 필요한 키, 사용 블록, 보드 상황을 기준으로 분류한다.
- 같은 기술이 반복되더라도 보드 상황과 모션 변형은 랜덤으로 바뀌어야 한다.
- 사용자가 특정 기술을 집중 연습할 수 있도록 기술 필터를 제공한다.

## 7. 초급 코스 상세 기능

### 7.1 문항 표시

- 앱은 현재 연습할 동작명과 대표 키를 표시한다.
- 모션 보드에는 해당 동작을 사용해야 자연스러운 테트리스 상황을 표시한다.
- 사용자가 아직 입력하지 않았을 때는 목표 위치 또는 고스트 위치를 은은하게 표시한다.

### 7.2 입력 처리

- 브라우저 기본 스크롤을 유발하는 키 입력은 연습 화면에서 막는다.
- 대소문자는 구분하지 않는다.
- `Space`는 공백 문자열이 아니라 하드 드랍 입력으로 처리한다.
- 연습 대상이 아닌 키는 시도 수에 포함하지 않는다.

### 7.3 피드백

- 정답이면 성공 모션, 성공 표시, 연속 성공 증가, 다음 문항 이동을 수행한다.
- 오답이면 실패 표시, 연속 성공 초기화, 정답 키 안내를 수행한다.
- 오답 후 바로 다음 문항으로 넘어가지 않고, 사용자가 같은 문항을 다시 시도할 수 있어야 한다.
- 연속 성공 수가 일정 기준을 넘으면 더 다양한 변형 모션을 우선 출제한다.

## 8. 중급 코스 상세 기능

### 8.1 기술 문항

중급 문항은 단일 키가 아니라 키 시퀀스를 다룬다.

예시:

| 기술 | 예시 시퀀스 |
| --- | --- |
| T-Spin Single | `ArrowLeft` → `Z` 또는 `X` → `Space` |
| T-Spin Double | `ArrowRight` → `X` → `Space` |
| Mini T-Spin | `ArrowLeft` → `Z` → `ArrowDown` |
| Tuck | `ArrowRight` → `ArrowDown` → `ArrowLeft` |
| 180도 회전 삽입 | `ArrowLeft` → `A` → `Space` |
| 홀드 활용 | `C` → 이동 → 회전 → `Space` |

실제 키 시퀀스는 보드 상황과 블록 방향에 따라 달라질 수 있다.

### 8.2 중급 모션

- 기술 시작 전 보드 상태를 보여준다.
- 각 입력 단계마다 블록 이동 또는 회전 모션을 재생한다.
- 사용자가 올바른 시퀀스를 입력하면 최종 배치와 라인 클리어 결과를 보여준다.
- 시퀀스 중간에 오답이 발생하면 현재 단계에서 멈추고, 잘못 입력한 키와 기대 키를 안내한다.
- T-Spin 계열 문항은 회전 삽입 순간과 라인 클리어 결과를 명확히 보여준다.

### 8.3 중급 난이도

중급 코스는 난이도를 3단계로 나눈다.

| 난이도 | 설명 |
| --- | --- |
| 중급 1 | 목표 키 시퀀스를 일부 표시하고, 보드 상황도 단순하게 구성 |
| 중급 2 | 목표 시퀀스를 숨기고 기술명과 보드 상황만 표시 |
| 중급 3 | 실전과 유사하게 다음 블록/홀드까지 고려하는 문항 제공 |

## 9. 상태 및 데이터 모델

### 9.1 PracticeItem

연습 문항은 다음 정보를 가진다.

```ts
type PracticeItem = {
  id: string;
  course: 'beginner' | 'intermediate';
  title: string;
  description: string;
  expectedKeys: string[];
  motionVariants: MotionVariant[];
  difficulty: 1 | 2 | 3;
  tags: string[];
};
```

### 9.2 MotionVariant

모션 변형은 다음 정보를 가진다.

```ts
type MotionVariant = {
  id: string;
  piece: 'I' | 'O' | 'T' | 'S' | 'Z' | 'J' | 'L';
  boardBefore: number[][];
  pieceBefore: PieceState;
  pieceAfter: PieceState;
  highlights: BoardHighlight[];
  animationType: 'move-left' | 'move-right' | 'soft-drop' | 'hard-drop' | 'rotate-cw' | 'rotate-ccw' | 'rotate-180' | 'hold' | 'sequence';
};
```

### 9.3 PracticeStats

사용자 통계는 최소한 다음 정보를 가진다.

```ts
type PracticeStats = {
  attempts: number;
  correct: number;
  streak: number;
  perItemAttempts: Record<string, number>;
  perItemCorrect: Record<string, number>;
};
```

## 10. 성공 기준

### 10.1 초급

- 사용자는 초급 코스에서 8개 기본 키를 모두 연습할 수 있다.
- 각 키는 최소 3개 이상의 서로 다른 모션 상황으로 출제된다.
- 랜덤 모드에서 키가 무작위로 출제된다.
- 정답 입력 시 해당 키의 모션이 재생된다.
- 오답 입력 시 사용자 입력에 대한 피드백과 정답 안내가 제공된다.
- 연속 성공, 정확도, 시도 수가 정상적으로 갱신된다.

### 10.2 중급

- 사용자는 T-Spin 계열 기술을 최소 3종 이상 연습할 수 있다.
- 기술 문항은 키 시퀀스 단위로 채점된다.
- 각 기술은 여러 보드 상황과 모션 변형으로 랜덤 출제된다.
- 정답 시 최종 배치와 라인 클리어 결과가 시각적으로 표현된다.
- 오답 시 실패한 단계와 기대 입력이 표시된다.

## 11. 비기능 요구사항

- 프론트엔드는 Vite + Vanilla JavaScript 기준으로 구현한다.
- 키 입력 반응은 사용자가 지연을 느끼지 않도록 즉시 처리한다.
- 모션 애니메이션은 빠르게 반복 연습할 수 있도록 300ms에서 900ms 사이를 기본값으로 한다.
- 모바일 환경에서는 키보드 입력 대신 화면 버튼 연습 모드를 제공할 수 있다.
- 색상만으로 정답/오답을 구분하지 않고 텍스트 또는 아이콘 피드백도 함께 제공한다.
- 통계는 우선 브라우저 메모리에 저장하고, 이후 필요 시 LocalStorage 또는 백엔드 저장으로 확장한다.

## 12. 구현 우선순위

1. 초급 키 데이터와 랜덤 출제 로직
2. 초급 모션 보드와 키별 3개 이상 모션 변형
3. 정답/오답 피드백과 통계
4. 초급 순차/랜덤 모드 전환
5. 중급 기술 데이터 구조
6. T-Spin Single, T-Spin Double, Mini T-Spin 문항
7. 중급 랜덤 출제와 기술 필터
8. 중급 난이도 단계

## 13. 제외 범위

초기 버전에서는 다음 기능을 필수로 보지 않는다.

- 온라인 계정 및 로그인
- 사용자별 장기 기록 저장
- 랭킹 시스템
- 실제 테트리스 전체 게임 플레이 모드
- 멀티플레이
- 커스텀 키 바인딩

단, 커스텀 키 바인딩은 접근성 및 사용자 선호 측면에서 이후 확장 후보로 둔다.
